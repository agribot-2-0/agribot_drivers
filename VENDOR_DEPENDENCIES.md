# Vendor packages obtained separately

The original archive includes Advantech CAN, I/O and video driver installers, vendor source archives and precompiled shared libraries. Their redistribution rights were not established, so .run, .tar/.tar.gz/.tar.xz/.tgz and .so payloads are not included in this public history.

Obtain the driver version appropriate to your hardware from the original vendor under its terms. The archived paths/installation scripts identify expected package locations, including CAN advSocketCAN_V1.0.1.0, I/O Linux driver 4.0.2.0 (and 4.0.3.0 in history), PCI driver packages and the video driver V1.1.0.101.636_PAL_MZ0380. Install them separately before using the corresponding scripts. The Livox-SDK submodule remains an upstream dependency under its own license. Copied vendor I/O examples and SDK headers are also omitted; obtain these with the vendor package.
